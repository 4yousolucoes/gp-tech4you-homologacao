# TECH4YOU • Homologação

[Abrir a aplicação](https://4yousolucoes.github.io/gp-tech4you-homologacao/)

Entre com a conta fornecida pelo gestor. No menu Integrações, consulte as orientações de uso do Claude Code. Solicite ao gestor o manual técnico e o instalador para configurar a conexão no seu computador.

Após conectar, consulte um projeto de teste e compare as tarefas com o quadro da aplicação. Registre os resultados pelo canal interno combinado com sua equipe.
